# 🏔️ Diorama — Shader Project

A diorama scene built in **Unity (URP)** to explore **Shader Graph**, featuring custom shaders for water, clouds, fog, mountains, and a full day/night cycle.

---

## ✨ Shaders

| Shader | Description |
|--------|-------------|
| **FarCry Water** | Animated water surface with noise-based waves |
| **Clouds** | Procedural cloud shader |
| **Fog** | Atmospheric fog effect |
| **Mountains** | Terrain shading |
| **Custom Light** | Manual Phong lighting model (ambient, diffuse, specular, Fresnel, refraction) |

---

## 🌗 Day / Night Cycle

A script rotates the directional light over a configurable day duration and propagates the light direction, color, and a night blend factor globally to all shaders in real time.

---

## 🛠️ Built With

- **Unity 6** — Universal Render Pipeline (URP)
- **Shader Graph**
- **C#**
